# 구독 케어 안내 도우미

LG 가전 구독(렌탈) 고객에게 **제품별 케어 플랜을 설명하기 위한 현장 매니저용 모바일 웹 도구**입니다.

제품을 검색해 카드를 펼치면 플랜(요금제)별로 어떤 케어를 언제 받는지 한눈에 확인할 수 있습니다.

> **현재 상태:** 프로토타입 (단일 HTML 파일) · [배포 중](https://lg-care-guide.pages.dev) · 정식 웹 서비스로 전환 예정

---

## 빠른 시작

빌드 단계가 없습니다. 배포된 주소를 그대로 열어보시면 됩니다.

**https://lg-care-guide.pages.dev**

로컬에서 수정하며 확인할 때는 간단한 정적 서버를 띄우세요.

```bash
npx serve .
```

`start index.html` 처럼 파일을 직접 열어도 동작하지만, 브라우저가 `file://` 에서는 서체 파일을 차단합니다. LG Smart 가 설치되지 않은 PC 라면 기본 서체로 보이니 주의하세요.

모바일 화면을 기준으로 설계되어 있어, 개발자도구의 모바일 뷰(375px 내외)와 데스크톱 폭을 함께 확인하는 것을 권장합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 애플리케이션 전체 (HTML·CSS·JS 인라인) |
| `fonts/` | LG Smart_H 서체 — 배포용 WOFF2 4종(합계 1.69MB)과 원본 TTF 4종 |
| `tools/` | WOFF2 서브셋 생성 스크립트 |
| `README.md` | 이 문서 |
| `.gitignore` | OS·에디터 파일 및 웹 전환 대비 Node 관련 항목 |

외부 라이브러리·CDN 요청이 **없습니다.** 제품 아이콘은 인라인 SVG, 서체는 `fonts/`에서 직접 제공합니다.

### 서체

LG 전자 공식 서체 **LG Smart_H** 를 사용합니다. `@font-face` 의 `local()` 이 먼저 선언되어 있어, 서체가 설치된 기기에서는 파일을 내려받지 않습니다.

브라우저가 실제로 내려받는 것은 원본 TTF가 아니라 **WOFF2 서브셋**입니다.

| | 원본 TTF | 배포용 WOFF2 | |
|---|---|---|---|
| 합계 | 13.9MB | **1.69MB** | 88% 감소 |

한글 11,172자 전체를 포함하므로 케어 데이터에 어떤 한국어를 넣어도 글자가 깨지지 않습니다.

| 굵기 | 용도 |
|---|---|
| Bold (700) | 앱 제목, 제품명, 타임라인 제목, 활성 플랜 탭 |
| SemiBold (600) | 배지, 바로가기 칩, 케어 항목명, 레인 라벨, 플랜 탭 |
| Regular (400) | 상세 값, 검색 입력 — **기본 서체** |
| Light (300) | 부제, 플랜 목록, 메타 정보, 항목 설명, 축 눈금, 범례 |

#### WOFF2 재생성

원본 TTF를 교체했거나 문자 범위를 바꿀 때만 실행하면 됩니다.

```bash
cd tools && npm install && npm run build:fonts
```

용량을 더 줄이려면 `tools/build-fonts.mjs` 의 `COVERAGE` 를 `'used'` 로 바꾸세요. 페이지에 실제로 쓰인 글자만 담아 **0.15MB** 까지 줄지만, 텍스트가 바뀔 때마다 재생성해야 합니다.

## 주요 기능

### 1. 초성 검색
제품명·플랜명·케어 항목명을 대상으로 검색합니다. 한글 초성 입력을 지원해 `ㅅㅌㄱ` → `세탁기` 로 찾을 수 있습니다. 입력과 동시에 상위 6건이 자동완성 드롭다운으로 표시되고, 일치 부분은 하이라이트됩니다.

### 2. 아코디언 카드
제품 카드는 한 번에 하나만 열립니다. 열리는 시점에 본문을 렌더링하는 지연 방식이라 초기 로딩이 가볍습니다.

### 3. 플랜 전환
카드 안의 세그먼트 탭으로 프리미엄 / 라이트 등 플랜을 전환하면 본문 전체가 다시 그려집니다. 최상위 플랜에는 ★ 표시와 골드 배경이 적용됩니다.

### 4. 케어 주기 타임라인 ⭐
이 도구의 핵심 기능입니다. `"6개월마다, 총 12회"`, `"48개월차, 1회"` 같은 **한글 서술 문자열을 정규식으로 파싱**해서 계약 전 기간 축 위에 점으로 시각화합니다.

- 3개 레인: 방문관리(자주색) · 자가관리(청록색) · 필터·소모품(주황색)
- 축 눈금은 12개월 이상이면 자동으로 "년" 단위로 표기
- 전체 기간(horizon)은 데이터에서 자동 산출

### 5. 항목 설명 토글
각 케어 항목 옆 `i` 버튼을 누르면 그 항목이 무엇인지 한 줄 설명이 펼쳐집니다.

## 수록 데이터

제품 6종의 플랜별 케어 내용이 `index.html` 안의 `DATA` 배열에 하드코딩되어 있습니다.

| 제품 | 세부 | 플랜 |
|---|---|---|
| 세탁기 | 트롬 | 프리미엄 / 라이트플러스 / 라이트 |
| 냉장고 | STEM 얼음정수 | 프리미엄 / 라이트 / 기본 |
| 정수기 | — | 스탠드형 / 6개월형 / 12개월형 |
| 공기청정기 | — | 프리미엄 / 라이트플러스 |
| 에어컨 | — | 프리미엄 / 라이트플러스 |
| 스타일러 | 3벌 | 프리미엄 / 라이트 / 베이직 |

각 제품·플랜마다 아래 6개 항목을 가집니다.

| 항목 | 의미 |
|---|---|
| 방문관리 | 매니저가 정기 방문해 관리 |
| 자가관리 | 고객이 직접 수행 |
| 필터·소모품 | 소모품 교체 주기 및 제공 방식 |
| 살균·클리닝 | 위생 관리 (방문 시 함께 진행) |
| 성능 점검 | 작동 점검 (방문 시 함께 진행) |
| 무상 서비스 | A/S 등 계약 기간 중 무상 제공 |

### 데이터 구조

```js
{
  name:  "세탁기",                              // 제품명
  sub:   "트롬",                                // 부제 (없으면 "")
  icon:  "🧺",                                  // 검색 칩에 쓰이는 이모지
  tiers: ["프리미엄", "라이트플러스", "라이트"],  // 플랜 목록 (첫 번째가 최상위)
  items: [
    {
      label: "방문관리",
      vals:  ["24개월마다, 총 3회", "6개월마다, 총 12회", "6개월마다, 총 12회"]
      //      └ tiers 와 순서·개수가 반드시 일치해야 함
    }
  ]
}
```

`vals` 의 각 문자열은 타임라인 파서가 읽습니다. 아래 패턴을 인식합니다.

| 패턴 | 해석 | 예시 |
|---|---|---|
| `N개월마다` + `총 M회` | 반복 이벤트 M회 | `6개월마다, 총 12회` |
| `N개월차` | 특정 시점 1회 | `48개월차, 1회` |
| `-` 또는 빈 문자열 | 해당 없음 | `-` |
| 줄바꿈(`\n`) | 여러 이벤트 구분 | `워터 필터 교체\n퓨어프레시 필터 교체` |

데이터 추가 시 이 표기를 따르지 않으면 상세 목록에는 텍스트가 표시되지만 **타임라인에는 점이 찍히지 않습니다.**

## 알려진 이슈

웹 전환 시 함께 정리하면 좋을 항목들입니다.

| 이슈 | 내용 |
|---|---|
| 미사용 `img` 필드 | 각 제품에 LG 공식 이미지 URL이 있으나 코드에서 사용되지 않음 (인라인 SVG로 대체된 흔적) |
| 정수기 `"동일"` 표기 | 6개월형·12개월형의 일부 항목 값이 문자 그대로 `"동일"` 이라 화면에 그대로 노출됨 |
| 공기청정기 방문관리 | `3개월마다`와 `6개월마다` 두 줄이 한 칸에 들어 있어 타임라인에 두 세트가 동시에 표시됨 (모델별 차이로 추정) |
| `highlight()` 인덱스 | 공백 제거 기준 위치를 원본에 적용해, 공백이 있는 텍스트에서는 하이라이트가 어긋날 수 있음 (현재 제품명에는 공백이 없어 미발생) |
| 미사용 변수 | `renderTimeline()` 의 `shapes` 변수가 선언만 되고 쓰이지 않음 |
